# Backend Learning Labs

A collection of hands-on Python exercises exploring search,
asynchronous messaging, and database-backed web applications.

## Examples

- **Elasticsearch:** Indexing, search queries, analyzers, and Docker setup.
- **RabbitMQ:** Work queues, message routing, topics, and remote procedure calls.
- **Flask + PostgreSQL:** Student-record CRUD operations and database integration.

## Technologies

Python · Elasticsearch · RabbitMQ · Flask · PostgreSQL · Docker

## Project Status

These are learning exercises rather than production applications.
Some examples require additional local configuration.
The Flask example is incomplete because its HTML templates are missing.
